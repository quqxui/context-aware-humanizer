# 中文聊天

用于微信私聊、日常问候、道歉、支持对话和关系沟通。根据双方关系调整称呼、直接程度和句子长短，让对方容易理解，也保留发送者的边界。

## 使用实例

以下均为自拟示例，只演示改写方式，不是模型评测结果。

### 示例一：说明今晚的不确定性

**需求：** 改成发给朋友的简短消息，保留今晚可能看不了、明早可以帮忙的意思。

**原文：** 考虑到我今晚需要上课，我可能无法在今晚看这份稿子；但明天早上我可以帮你看。

**改写：** 我今晚要上课，可能看不了这份稿子；明早可以帮你看。

**为什么：** 去掉重复的时间表述，保留上课的原因。“可能看不了”和“可以帮忙”都没有变成确定承诺。

### 示例二：拒绝今天的通话

**需求：** 礼貌拒绝今天的通话，保留明天有条件、也不确定的空闲时间。

**原文：** 我今天没有时间参加这个电话。如果你在明天下午三点以后仍然需要聊，我到那个时候可能会有空。

**改写：** 我今天没空参加这个电话。如果明天下午三点后你还需要聊，我到时可能有空。

**为什么：** 今天无法参加是确定的；明天是否有空仍然不确定，也取决于对方是否还需要聊。没有补道歉、理由或新的安排。

## 语气怎么选

| 需要的效果 | 写法 |
|---|---|
| 亲切 | 用关系允许的称呼和自然措辞，不增加亲密程度 |
| 直接 | 先给答复，再补必要原因 |
| 安抚 | 回应原文中的担忧，说清已知情况，不承诺未知结果 |
| 表明边界 | 先说能否做到，再保留原文已有的替代安排 |

## 中文聊天的写法

- 保留原文的简繁体和地区用语。不要默认所有人都使用同一套网络口语。
- 关系决定称呼；不要自动加“亲”“宝子”“姐妹们”，也不必每句话都加“您”。
- 可以省略重复的主语，但不能让人分不清谁来做。“我”“我们”“你们”不能互换。
- “能”“可以”“会”“尽量”“可能”含义不同。客气一点不等于把确定要求改成可选项。
- 去掉“关于这件事情，我想表达的是”等空铺垫，保留有用的情绪、强调和解释。
- 短消息可以只写一句。敏感话题按实际内容组织回应、答复和后续安排，不强加完整模板。
- 不强行加语气词、表情、玩笑或“有问题随时找我”。原文已经自然时可以不改。

## 交付方式

默认只给可直接发送的消息。用户要求多个版本时，才提供相应语气的候选；称呼等关键关系不明且影响答复时，再问一个具体问题。
